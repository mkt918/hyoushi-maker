# 表紙メーカー

プリント冊子の表紙（B4横／A4横／A3横）を、PowerPoint のようにキャンバス上で自由配置して印刷・PDF化するツール。`index.html` を開くだけで動く（ビルド・サーバー不要）。

## 使い方
1. `index.html` をブラウザで開く（初期状態は元ネタの表紙の型）
2. 要素をクリックで選択、ドラッグで移動、角のハンドルでサイズ変更
3. テキストはダブルクリックで編集。画像は枠へドロップ／Ctrl+V／ダブルクリックで選択
4. 画像をダブルクリック＝トリミング（中をドラッグで位置調整、ホイールで拡大縮小、枠のハンドルで切り取り範囲）
5. 「この表紙を印刷」→ 送信先「PDFに保存」または実機プリンター。用紙は B4、余白「なし」、倍率100%

ショートカット: Del 削除 / Ctrl+D 複製 / Ctrl+C,V コピペ / Ctrl+Z,Y 戻す・進む / 矢印 微調整 / Tab 次の要素 / Alt でスナップ解除

## 背景
元ネタは手元の表紙PDF（原価計算の考査プリント冊子の表紙6枚、実寸はA4横）。
枠線＋上にタイトル＋左に画像＋右下に注意書き枠と番号・名前欄、という型を初期配置にしてある。
初版はフォーム入力式だったが、「PowerPoint のようにドラッグで配置・トリミングしたい」との要望で自由配置式に作り直した（2026-10-06）。

## 仕組み
- 要素は text / image / name（番号・名前欄）/ rect（枠線）の4種。座標・サイズはすべて `cqw`（ページ幅の1%）で、用紙を変えても比率が保たれる
- 画像は「枠」と「中身（cx, cy, cw）」を別々に持つ。通常のリサイズは中身ごと拡大縮小、トリミング中のリサイズは枠だけ変える
- 画像データは `state.assets` に分離（履歴＝undo に画像を複製しないため）。長辺2400pxのJPEGに縮小
- 編集内容は IndexedDB に自動保存。複数の表紙を左のサムネイル一覧で管理し「全部まとめて印刷」で1PDFにできる

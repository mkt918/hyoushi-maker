# 表紙メーカー

プリント冊子の表紙（B4横／A4横／A3横）を、PowerPoint のようにキャンバス上で自由配置して印刷・PDF化するツール。
`index.html` を開くだけで動く（ビルド・サーバー不要）。公開版: https://mkt918.github.io/hyoushi-maker/

## できること
- **テンプレート8種**: スタンダード／サイドバー／ポップ／エレガント、白黒印刷向けのモノクロ帯／タブ見出し／マンガ大きめ／チェックリスト。途中で切り替えても画像・タイトル・注意書き・画像の上の吹き出しを引き継ぐ
- **白黒表示**: 印刷は基本グレースケールなので、画面も白黒で確認できる（初期オン。印刷データ自体は変えない）。色の候補にグレー10段階
- **自由配置**: クリックで選択、ドラッグで移動、ハンドルでリサイズ。他の要素や中心線にスナップ（Alt で解除）。位置・サイズは mm でも入力できる
- **画像**: ドロップ／Ctrl+V／ダブルクリックで挿入。ダブルクリックでトリミング（中をドラッグ、ホイールで拡大縮小）。「縦横比を固定」を外すと縦横別々に伸縮
- **画像の補正（マンガ向け）**: 元画像は残したまま、表示と印刷のときだけ加工する。灰色っぽい背景を白く／黒をくっきり／コントラスト／シャープ／2階調化を段階スライダーで、「弱・中・強」のワンタッチと「自動で背景を白く」も。傾き補正（スライダー、または水平にしたい線の2点クリック）、ゆがみ補正（四隅をドラッグして台形を直す）。補正の内容は書き出しファイルにも保存される
- **マンガのセリフ改変**: 「＋ セリフ」で白塗り・縦書きの文字を元のセリフに重ねて書き換える。文字が増えると枠が自動で広がる
- **吹き出し**: 丸／角丸／考え中（もくもく）／叫び（ギザギザ）。オレンジの丸でしっぽの向きを変える。縦書き・横書きどちらも可
- **文字の装飾**: フォント18種（基本8＋マンガ・ポップ10。Google Fonts＋PC内蔵）、新しいテキストは背景白塗りが初期設定、pt 指定、太字、縦書き、行間、字間、色、「文字を枠に収める」
- **枠・背景の装飾**: 塗り、線の太さ（mm）・色・種類（実線／破線／点線／二重線）、角の丸み、影
- **図形**: 枠線、塗りの四角（帯）、丸、横線
- **その他**: 元に戻す／やり直し、表紙の追加・複製・並べ替え、印刷ガイド（各辺10mm）、ファイルへの書き出し・読み込み（画像込みの .json）

## 使い方
1. ページを開く（初期状態はテンプレート1）
2. 編集する。ショートカット: Del 削除 / Ctrl+D 複製 / Ctrl+C,V コピペ / Ctrl+Z,Y 戻す・進む / 矢印 微調整 / Enter 文字編集 / Tab 次の要素
3. 「印刷」→ 送信先「PDFに保存」または実機プリンター。用紙は表紙と同じサイズ、余白「なし」、倍率100%

## 背景
元ネタは手元の表紙PDF（原価計算の考査プリント冊子の表紙6枚、実寸はA4横）。テンプレート1がその型。
- 初版はフォーム入力式 → 「PowerPoint のようにドラッグで配置・トリミングしたい」で自由配置式へ
- 第3版で、テンプレート4種・フォント・枠装飾に加え、マンガの1コマのセリフを楽しく改変するための白塗り縦書きセリフと吹き出しを追加（2026-10-06）

## 仕組み
- 要素は text / image / name（番号・名前欄）/ rect（図形）/ bubble（吹き出し）の5種。座標・サイズはすべて `cqw`（ページ幅の1%）
- 画像は「枠」と「中身（cx, cy, cw, ch）」を別々に持つ。通常リサイズは中身ごと、トリミング中は枠だけを変える
- 吹き出しは SVG。輪郭としっぽを1本のパスで描くので継ぎ目が出ない。しっぽの先（tx, ty）は要素の左上からの相対座標
- 画像データは `state.assets` に分離（undo 履歴に画像を複製しないため）。長辺2400pxのJPEGに縮小
- 編集内容は IndexedDB に自動保存
